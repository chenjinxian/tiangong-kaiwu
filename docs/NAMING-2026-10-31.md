# 命名迁移 2026-10-31：OpenCloud → LubanCAD

依据根 `CLAUDE.md` 的命名家族（平台 **天工开物** / 产品 **鲁班CAD（LubanCAD）** /
几何内核 **真形（TrueForm）** / 约束求解器 **绳墨（ShengMo）**；代码包 `@luban-cad/*`），
退役代码与线上契约中的旧品牌 `OpenCloud`。本记录只描述**现行代码/契约**；2026-10-29
的迁移/上游同步记录中的旧目录名 `open-cloud-cad/` 是历史事实（该目录已删除），保留不改写。

## 1. 映射

| 旧 | 新 |
|---|---|
| `OpenCloudRpcInterface`（文件/类/`interfaceName`） | `LubanRpcInterface` |
| `OpenCloudRpcImpl`（后端实现） | `LubanRpcImpl` |
| `OpenCloudIpcInterface` | `LubanIpcInterface` |
| `openCloudIpcChannel` / `"open-cloud-ipc"` | `lubanIpcChannel` / `"luban-ipc"` |
| `OpenCloudIpcHandler` | `LubanIpcHandler` |
| `OpenCloudCADError` / `OpenCloudCADErrorCode` / `isOpenCloudCADError` | `LubanCADError` / `LubanCADErrorCode` / `isLubanCADError` |
| `OpenCloudCADSchema.ts`（文件） | `CadFeatureSchema.ts` |
| `OPENCAD_SCHEMA_*` | `CAD_FEATURE_SCHEMA_*` |
| GLTF `extras.openCloudCad` | `extras.lubanCad` |

## 2. 线上契约（必须同批部署）

- **RPC interfaceName**：`LubanRpcInterface`（原 `OpenCloudRpcInterface`）。RPC URL 路径
  由 interfaceName 生成，web 与 modeling-server 必须同批重建；仓库内旧 P2.7 产物
  `backend-20261031-p27`（`dist-backend/`）仍实现旧名，**不兼容**，发布前必须重建 MS 产物。
- **IPC channel**：`luban-ipc`（原 `open-cloud-ipc`）。共享常量 `lubanIpcChannel` 两端同源，
  不涉及持久化状态。
- 本地验证使用新后端源码构建（日志 `LubanIpcHandler registered on channel: luban-ipc`、
  `LubanRpcInterface registered`；`/rpc/metadata` 路径为 `LubanRpcInterface-1.0.0-*`），
  新 web 镜像 revision `3bc7801a8644`。

## 3. 持久化兼容例外（未改）

EC schema **`OpenCloudCAD`（alias `ocad`）** 已写入既有 iModel（CadFeature 参数化历史）。
本次仅重命名文件/常量（`CadFeatureSchema.ts` / `CAD_FEATURE_SCHEMA_*`），**schemaName/alias
保留**；直接改名会让旧文档读不到 CadFeature。彻底退役该字符串需要单独的 EC schema
迁移（建新 schema + 数据迁移/双读），不在本次命名清理范围。
