# B6 M-A5.2 设计：面/边子实体选择 + 多体性能护栏

日期：2026-10-29
状态：设计已确认，待 spec 复核 → 实现计划
BASE：public `e467e59`（M-A5.1 + #45 收口）；private `0002e61`；MS `backend-20261028c`。
性质：full A 第二切片；**web-only**，shared/MS 契约不变。
来源：M-A5.1 复审/全量审计（selection 子实体缺失、127-body 无实测）。

## 1. 目标与非目标

### 目标

1. 在 part-studio 提供**显式面/边选择模式**：可连续多选面或边，显示精确子实体高亮，打开
   owner-aware 右键菜单。
2. 面/边选择可执行的安全动作：
   - 隐藏所属实体（整 body）；
   - 选中所属实体（退出子实体模式，走既有 body 选择/树高亮通道）。
3. 建立多体性能护栏：
   - 私有仓 in-process 127-body 基准（server 读/写/冷重建）；
   - web 真栈 multi-body 性能探针（N=20 默认，可选 50/90；tree/edit/fit/FPS/tile 指标）。
4. 不引入面/边删除、面级特征编辑或子实体持久高亮 overlay。

### 非目标

- `DeleteSubEntities` 直改/D7 隔离；面/边删除与特征归属。
- 面级外观（appearance-for-face）实现；保留现有 gated 占位。
- 子实体持久高亮（工具退出后精确面/边 overlay）：无受支持 API，见 §8。
- MS/shared/schema 变更；`resolveEdgeRef` 泛化（边界/非流形边不可选）。
- 生产热路径优化；除非性能探针实测失败，另行立项。

## 2. UX 与状态机

### 2.1 模式

- store 新增 `canvas.selectionMode: 'body' | 'face' | 'edge'`，缺省 `body`。
- ribbon 新增「选择」组，两枚 toggle：「选择面」「选择边」。
  - 点击进入对应模式（已在该模式再点则退出回 body）。
  - 模式激活时 `aria-pressed=true`；body 模式无激活钮。
- 默认点击仍由 iTwin Select 选 body；子实体模式启动专用工具。

### 2.2 生命周期

```
body --点击 选择面/边--> face/edge（启动 SubEntitySelectTool；清空 canvas 选择）
face/edge --Esc / 工具 onEnded / 再点同钮--> body（清空子实体选择，返回默认 Select）
face/edge --dialog 打开--> 不自动切换；模式按钮在对话框打开时禁用
```

- 子实体模式同时只允许一个工具实例。
- 右键在子实体模式下**不退出工具**：保留工具装饰并打开 CanvasContextMenu；Esc 仍是退出。
- 连接切换/卸载：停止工具、清空子实体选择、回 body。

### 2.3 拾取

- 面：`resolveFaceRef(connectionKey, ownerElementId, cacheSubEntityId)`。
- 边：复用 `resolveEdgeRef(...)`；接受“恰两邻面”的流形边，边界/非流形边不可选（工具
  toast/日志诚实提示，不落选择）。
- `addSubEntity(elementId, props)` 的 `elementId` 即 owner `bodyKey`。
- 连续点击累加选择；同 topology 去重；重复点击不重复加项（不做点选取消；退出模式清空）。
- 解析失败：Error toast，不写入 store；工具装饰可在下次刷新时消失。
- 视觉：`LocateSubEntityTool` 自带的子实体装饰；退出模式即清理。**不伪造持久高亮**。

## 3. 数据模型

```ts
type CanvasSelectionMode = 'body' | 'face' | 'edge';

interface CanvasSelection {
  kind: 'part' | 'face' | 'edge' | 'vertex' | 'feature';
  id: string;                       // part=bodyKey；face/edge=`${kind}:${nodeId}:${entityId}`
  label?: string;
  featureType?: string;
  ownerBodyKey?: string;            // face/edge 必填
  topologyId?: LubanTopologyId;     // 持久拓扑 id（edge 用 ref.edge）
}
```

- store `canvas.selectionMode` + `setSelectionMode`；切模式时清空 `canvas.selection`
  （tree.selectedNodeIds 不动）。
- 选择相等键扩展为 `[kind,id,label,ownerBodyKey,topologyId.nodeId,topologyId.entityId]`，
  防 owner/topology 变化被当作相等。
- labels：zh/en「面 N」/「边 N」或「面」/「边」+ owner 名称由 UI 解析；不做面→feature
  推测。

## 4. 工具与桥接架构

### 4.1 SubEntitySelectTool

新文件 `apps/web-next/src/modules/part-studio/tools/modeling/SubEntitySelectTool.ts`：
- 继承 `LocateSubEntityTool`，构造 opts：
  ```ts
  interface SubEntitySelectOptions {
    kind: 'face' | 'edge';
    connectionKey: string;
    onPicked: (selection: CanvasSelection) => void;
    onEnded: () => void;
  }
  ```
- 面/边 `wantSubEntityType`；BRep solid/surface cache filter 同 FilletEdgePickTool；
  **不使用** fillet 的 laminar/smooth 过滤或邻接前置过滤（边邻接由 resolveEdgeRef 裁决）。
- `addSubEntity` 立即异步 resolve，成功后 `onPicked`；失败 Error toast。
- `onCleanup` → `onEnded`；右键 reset 覆盖为不退出（保留 context menu）。
- 直接构造 + `.run()`（沿用 FilletEdgePickTool 的无 option-injection 启动方式）。

### 4.2 useSubEntitySelection

新 hook（PartStudioSession 单点挂载）：
- 监听 `selectionMode`；进入 face/edge 时构造并启动工具（需 connection）；退出/卸载停止。
- 模式切 body 时清空子实体选择；工具自然结束也回 body。
- dialog.active 时禁止启动；若打开 dialog 则停止工具回 body（防御）。
- 工具结束若模式仍匹配，setSelectionMode('body')；不自动重启。

### 4.3 元素级桥门控

`useCanvasBodySelection` 新增 `enabled`（或 mode 参数）：
- 仅在 `selectionMode === 'body'` 时订阅 `connection.selectionSet.onChanged`；
- 非 body 模式退订，不写/不清 store；
- 模式切回 body 时重新同步当前 SelectionSet；
- 面/边选择**不写** `selectionSet`，不写 tree，避免 body bridge/树高亮互覆盖。

## 5. 右键菜单、隐藏与树

### 5.1 CanvasMenuItem 扩展

- 新增 `disabled?: boolean` + `disabledReasonKey?: string`；渲染 `disabled` + title。
- face/edge 分支：
  - 「隐藏所属实体」：`selection.map(s => s.ownerBodyKey ?? s.id)` 去重 → `hideNodes` +
    `EmphasizeElements.hideElements(owners, viewport, true)`；不使用 face/edge id。
  - 「选中所属实体」：新宿主回调 `onSelectOwner(bodyKey)`；实现=退出子实体模式 →
    `tree.selectedNodeIds=[bodyKey]` + SelectionSet.replace([bodyKey])（body bridge 重新启用
    后同步）；若多 owner，取 primary owner（尾项）并在 label 中说明。
  - 「删除」：保留渲染但 `disabled`，reason「面/边删除暂不支持」；不打开 HITL。
  - 视图命令保留；face 的 appearance gated 占位保留。
  - 「编辑特征」不新增（无 face→feature 归属）。
- part 分支行为保持不变。

### 5.2 树

- 不新增 face/edge 子节点；「选中所属实体」只走既有 body 行/高亮。
- 树行点击仍只写 tree selection；不与子实体选择双向同步。

## 6. 性能护栏

### 6.1 私有仓 in-process 基准

新 `modeling-server/src/feature/MultiBodyPerf.test.ts`（StandaloneDb + 真内核）：
- 用 `newBodyExt`（inline profile，无草图）造 N=10/50/127 体，固定网格布局。
- 测量并输出 JSON：
  - warm `getBodies()`、`getTree()`；
  - 一次增量 `applyOp`（newBody）；
  - `clearFeatureEngineCacheForTest()` + `rebuildAll()` 冷重建。
- 初始硬门槛（实现首跑校准，留 2× 余量，写入测试常量与文档）：
  - N=127：`getBodies < 1000ms`、`getTree < 1000ms`、单 insert `< 1000ms`；
  - N=127：`rebuildAll < 12s`（前端 15s timeout 的硬余量）；
  - 记录 N=10/50/127 缩放比；不设过窄 ratio 断言。
- 测试 timeout 600s；指标 evidence 输出到 gitignored 目录，跟踪常量与一次基线摘要。

### 6.2 Web 真栈探针

新 `apps/web-next/e2e/multibody-perf.spec.ts`，默认 N=20，env `PERF_MULTIBODY_N` 可设 50/90；
**opt-in**（`PERF_MULTIBODY=1`）以避免默认 34 例的 100 req/15min 预算被抢占。
- 建 scratch iModel → 打开编辑器（必须先开 briefcase）→ borrow lease → 1 normal extrude +
  N-1 newBody（inline profile）→ reload/等待 N 行。
- 指标：
  - tree-ready（N 行出现）时间；
  - 单次 body edit/suppress 后的刷新完成时间；
  - fit view 完成时间；
  - 空闲/轨道 FPS p95（复用现有 rAF 采样，门槛 18.2ms）；
  - `IModelApp.tileAdmin.statistics` 前后差：`totalCacheMisses/Dispatched/Completed`、
    `totalTileContentBytes`（**基线证据，不设 tile 门槛**）。
- 首跑校准常量（tree-ready < 3s、edit refresh < 1s、fit < 1s 等候选）；evidence 每 run
  timestamped JSON，gitignored；tracked 文档记录机器/commit/N/阈值。
- 失败策略：记录 blocker；**本切片不改生产热路径**。后续候选=批量 getBodies 源查询、
  合并 applyOp/onCommitted 双刷新、tree selected Set 化、限制 dialog 全 body 高亮；tile
  架构另立。

## 7. 测试与验收

- 单测：
  - tool resolve face/edge + owner/id/topology；失败不写 store；右键不退出/Esc/ended；
  - mode store 切换、bridge 门控（body 订阅/face-edge 退订/回 body 重同步）；
  - CanvasSelection 相等键含 owner/topology；
  - context menu owner hide/select owner；delete disabled；part/feature 菜单不回归；
  - 树不受子实体 pick 影响。
- 真栈：
  - **扩展现有 `e2e/newbody.spec.ts`**（复用既有两体 scratch/相机，不新增 iModel）：
    在 selection bridge 后、树删除前加入面模式拾面 → 菜单「隐藏所属实体/选中所属实体」；
    边模式拾边 → 同验；Esc 回 body；删除禁用；随后清空选择再继续既有删除/fillet 流程。
    body 默认选择不回归；全量 e2e 仍 34 例，不增加 scratch/RPC 预算。
  - multibody perf opt-in 跑 N=20 并记录 evidence（独立 iModel，不计入默认 34 例）。
- 门禁：web 单测、tsc/lint、全量 e2e、verify 17/17、web 镜像重建；无 MS 产物重建。
- 发布：默认代码 + 文档；Release 需用户确认（本切片无 MS 产物变化）。

## 8. 已知限制/风险

- **工具退出后无精确面/边高亮**：SelectionSet 不支持；编辑器 onCleanup 清装饰。不实现
  持久 overlay；模式退出即清选择。
- **面 split 语义**：`facesFromId` 可返回多片；本切片仅存一个持久 face id，不保证重建后
  视觉一片；登记。
- **边仅流形边**：resolveEdgeRef 邻接门禁；边界/非流形边不可选；不泛化契约。
- **右键冲突**：工具 reset 与 CanvasContextMenu 的冲突通过“右键不退出、Esc 退出”解决；
  真栈必须验证事件顺序。
- **无 face→feature 归属**：不提供面级“编辑特征”；“编辑驱动特征”留 backlog。
- **性能阈值机器相关**：私有基准门限定宽，web 探针先校准；tile 只记录基线。
- **限流**：N=20 perf 探针 opt-in，默认套件不加负担；跑前重启 MS。
