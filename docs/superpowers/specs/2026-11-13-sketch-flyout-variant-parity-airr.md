## 2. 决策与本切片

把上表全部变体纳入产品 UI（保持 live 顺序/文案），未实现项一律登记
**gated 能力引导**（点击说明真实原因，不写数据），不再缺项或静默：

1. 新增 gated 变体（8）：中点线 `sketchMidline`、椭圆 `sketchEllipse`、
   椭圆弧 `sketchEllipseArc`、样条控制点 `sketchSplineControlPoints`、
   交点 `sketchIntersection`、槽 `sketchSlot`、草图倒角 `sketchChamfer`、
   插入图像 `sketchInsertImage`（gated 集合 34→42）。
2. **圆锥位置纠正**：live 的「圆锥」在**圆弧**飞菜单（不在样条）；本产品从
   样条飞菜单移到圆弧飞菜单，文案改为「圆锥」，顺序与 live 一致
   （3 点/相切/圆心/椭圆弧/圆锥）。
3. 圆弧飞菜单顺序按 live 调整为 3 点 → 相切 → 圆心（此前圆心/相切互换）。
4. 圆飞菜单补「3 点圆」已由既有 PerimeterCircle 承担（文案沿用产品词表）。
5. 引导文案给出真实原因（新实体类型/求解器/后端、工具未实现、图像渲染等），
   中英同步；能力表/引导键集严格同步（capabilities.test 钉死）。

**非目标**：本切片不实现上述 8 个变体的几何能力（各自独立 AIRR/ADR）；
「结构」构造转换的交互对齐另行验证。
