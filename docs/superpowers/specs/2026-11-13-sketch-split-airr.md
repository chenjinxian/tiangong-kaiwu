## 2. 范围（首切片）

1. 工具 `Sketch.Split`（PrimitiveTool，requireWriteableTarget）：点击命中
   线/圆弧/三次贝塞尔样条 → 在点击处精确分割，一次 `updateSketch` 提交
   （可撤销）；工具保持存活可连续分割；Esc/右键结束。命中沿用 picker 的
   屏幕距离算法（≤5px），点击点经相机射线与草图平面求交反解局部坐标。
2. 几何：
   - **线**：点击参数 t 处新增显式点实体（新 id），第一段沿用原实体 id
     （原 p1 → 新点），第二段新 id（新点 → 原 p2）；两段共享新点，端点原有
     引用（显式点 id 或内联点）保持。construction 标记两段继承。
   - **圆弧**：按点击角度拆成两段弧（同一圆心引用/半径，角度区间首尾相接），
     第一段沿用原 id。
   - **三次贝塞尔样条**：de Casteljau 在点击参数处精确分裂为两段三次样条
     （第一段沿用原 id；fitPoints 丢弃，construction 继承）。
   - **圆**（live 两点语义）：第一次点击只挂起（工具提示
     「再选择一个点以分割闭合曲线。」），第二次点击同圆另一个位置 → 按两点
     角度拆成两段弧（扫角之和 = 2π；第一段沿用原 id；两点重合 → no-change）。
3. 约束语义（诚实登记）：与修剪同口径——**移除引用被分割实体的约束**
   （整段长度/端点关系不再对一半几何成立），其余约束原样提交、后端重解算
   兜底；不伪造“约束自动分配”。
4. 诚实拒收：periodic/非四次控制点/投影样条、点击落在端点附近（退化段）→
   no-change/unsupported，不写数据。
5. Ribbon：「修剪 ▾」飞菜单补第三项「分割」（无快捷键，顺序与 live 一致）。

**非目标**
- 分割点拖动 / 分割后自动删除段（用既有选择 + Delete）；
- 约束的智能重分配；
- 第一点待分割状态的画布标记（仅提示条，未画标记）。

## 4. 跨仓影响

无 shared/后端/schema/RPC 改动；纯前端 + 单测 + 真栈 e2e。

## 5. 测试

- 纯单测 `sketch-trim.test.ts` 增补 `splitSketchAt` **6 条**（文件 18/18）：
  线中点两段+共享点+约束移除+id 唯一、显式点引用保持、端点 no-change /
  单点圆 needs-second-point / 投影样条 unsupported、圆两点两段弧（扫角和
  2π、两点重合 no-change）、弧中点两段角度首尾相接、样条 de Casteljau
  两段控制点首尾相接。
- 真栈 `e2e/sketch-split.spec.ts` **两个用例分别 2 passed（37.6 s /
  40.9 s，含 auth setup）**：
  1. 线中点分割：`getSketch` 2 线 + 1 点（两线各自引用同一 point id、
     端点 ±10 mm）→ undo 回 1 线（点一并消失）；
  2. 圆两点分割：先正视草图平面 + 缩放到合适大小（角度对像素敏感）；第一点
     后仍为 1 圆 0 弧；第二点后 2 弧（π/2 + 3π/2）→ undo 回 1 圆。
- 回归：web 全量单测 **1759/1759**、tsc（含 e2e）/lint 绿。

## 6. 风险与回滚

- 约束移除可能导致尺寸丢失（与修剪同口径，文档明示）。
- 回滚：移除工具注册/飞菜单项/纯函数与测试；已分割数据是普通线/弧/样条，
  无迁移。
