日期：2026-11-13
状态：**已实现（简化切片，2026-11-13）**（用户指令：继续实现全部缺口）

  （`ui-evidence/ui-direct-mouse-20261112/87-onshape-isolate-dialog.png`；
  透明度同面板 `88-...`）。

## 2. 范围（本切片，显式简化）

1. 零件行「隔离…」启用：点击即隔离该零件——**会话级隐藏其它所有零件**
   （复用 `store.canvas.hiddenIds` 单一显示通道），并强制显示被隔离零件。
2. 视口上方出现横幅「已隔离 <name>（仅显示该零件）· 退出隔离」；退出时恢复
   隔离前的隐藏集（此前隐藏的零件继续保持隐藏，被隔离件若原为隐藏则恢复隐藏）。
3. 隔离只改显示态，不写 iModel、不进 undo 栈（Onshape 隔离同为视图态）。
4. 只读连接也可使用（显示动作，不受 canEdit 限制）。

**非目标 / 简化登记**
- Onshape 工具面板的目标选择/零部件控制/按连接或距离展开/在隔离中加选零件
  未实现——本产品仅“立即隔离单件 + 横幅退出”；
- 多选零件隔离、隔离状态持久化/命名视图未做；
- 与隐身的交互按“恢复隔离前隐藏集”处理（不做叠加规则）。

## 3. 复用矩阵

| 依赖 | 复用 | 说明 |
|---|---|---|
| `store.canvas.hiddenIds` | 既有隐藏/显示单一通道 | 无第二显示状态 |
| 零件树菜单 | 既有槽位 | 启用「隔离…」+ 回调 |
| `bodiesForDisplay` | 当前可见零件集 | 计算“其它零件” |
| 宿主 toast/横幅样式 | 既有视觉语言 | 新 `.part-studio-isolate-banner` |
