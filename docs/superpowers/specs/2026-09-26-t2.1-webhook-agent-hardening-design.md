# T2.1 webhook-agent 整治 设计

日期：2026-09-26
状态：设计已获用户确认（两项内嵌决策：镜像 MS logger 不引 pino；去重持久化用 JSON 文件）
上游：`docs/superpowers/specs/2026-09-26-platform-architecture-review-design.md`（T2.1 子项目）

## 目标

webhook-agent（平台最弱组件）达到内网交付底线：核心路径有测试、日志可检索、错误不静默、原生引擎生命周期配对、重启不丢去重状态。

## 决策记录

1. **Logger = 镜像 modeling-server 的 `utils/logger.ts`**（零依赖 JSON 行式，`config.LOG_LEVEL` 控制）。不引 pino/winston——与平台既有惯例一致，无新供应链面。
2. **去重持久化 = `data/processed-events.json`**（启动加载、追加写、TTL 清理对齐现有 2 分钟窗口语义）。不上 SQLite——量级为 5 分钟轮询去重。

## 1. 结构化日志

- 新 `webhook-agent/src/utils/logger.ts`（镜像 MS 版，服务名 webhook-agent）。
- 全量替换 `console.*`：baseline-generator(49)、main(39)、webhook-server(20)、forwarder(9)、processor(6)；删除伴随的 `eslint-disable-next-line no-console`。
- 保留：`config.ts` 拒启输出（stderr 直出，logger 未就绪）；测试文件内 console。
- `src/test-baseline.ts`（29 处 console 的开发脚本）：确认零引用后删除。

## 2. 测试从零到面（TDD）

| 模块 | 用例方向 |
|---|---|
| validator | HMAC 正/负/篡改 body/时序安全比较 |
| forwarder | 重试次数、退避、最终失败入队、成功清队（提取纯逻辑测） |
| processor | handler 注册/事件类型分发/wildcard/异常隔离（一 handler 挂不影响他者） |
| webhook-server | 入站 X-API-Key（WEBAGENT_API_KEY）校验 401/200 |
| baseline-generator 纯函数 | SAS 权限串构造、容器命名、URL 构造 |
| 去重持久化 | 加载/追加/TTL 过期清理/损坏文件容错 |

目标：12 → 40+ 用例。行为变更必须先有失败测试。

## 3. 空 catch 治理

先盘点 `catch {}` / `catch { // ignore` 全清单，逐点裁决：
- 可恢复/预期（如清理失败）→ `logger.warn` 带上下文；
- 掩盖错误（如转发失败被吞）→ `logger.error` 或 rethrow。
盘点表落入实施计划，不许新增空 catch。

## 4. IModelHost 生命周期

- 现状：baseline-generator 内 3 处 `IModelHost.startup()`（308/445/664 原行号，T1.2 改造后位置以 grep 为准）无配对 shutdown。
- 目标：服务入口（main.ts）启动时 1 次 `startup`；`SIGTERM/SIGINT` 处理器里 `IModelHost.shutdown()` + forwarder 尽力 flush + 进程退出；generator 内部 startup 调用删除（复用全局）。
- 测试：生命周期模块以可注入 start/stop 计数的单测验证「一次启动一次关闭」。

## 5. 去重状态持久化

- 现状：`main.ts` 恢复检查器 in-memory Set，重启丢失 → 重复触发 baseline 生成。
- 目标：`processedEventsStore`（load/has/add/persist/ttlSweep），文件 `data/processed-events.json`；`data/` 入根 .gitignore。
- 语义：TTL 窗口与现有 2 分钟一致（条目 `{id, ts}`）；损坏文件 → warn + 重建空库（不拒启）。

## 边界与不做

- 不改 WA 对外契约（HUB/MS 接口已在 T1.2/T1.3 定型）；不动 itwinjs-core/luban-cad。
- 结构化日志不引入请求关联 id 体系（T1.4 反代时统一考虑）。

## 验收

架构文档标准：核心路径测试覆盖；日志 JSON 可检索；重启后恢复检查器不重复触发（单测 + 手动重启冒烟）；`grep -c "console\."` 业务文件为 0（config/测试除外）。
