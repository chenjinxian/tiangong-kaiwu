# T1.5 事件与进度链单向化 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 消除 MS↔WA 双向 HTTP 环（retry 改 HUB 重新入队）；WA 转发至少一次投递（磁盘队列+重放+可观测）；`/ws` 推送激活、FE 轮询降级为兜底。

**Architecture:** HUB 加 requeue 本地扩展端点（状态翻回 notInitialized，恢复轮询拾取）；MS retry 路由内部转调 HUB、删 WEBAGENT_URL 全部引用；WA forwardQueueStore（JSON 磁盘队列）替换内存双结构、指数退避无限重试；shared 加 ws 消息契约，MS 进度回调广播 /ws，FE 订阅钩子 live 门控轮询。

**Tech Stack:** NestJS（HUB）、Express+ws（MS）、Vitest（三仓）、React hook（FE）。零新依赖。

**Spec:** `docs/superpowers/specs/2026-09-26-t1.5-event-chain-unidirectional-design.md`

## Global Constraints

- MS→WA HTTP 边消失硬证据：`grep -rn "WEBAGENT_URL" modeling-server/src` = 0（MS config 的 WEBAGENT_API_KEY 字段与 .env.example 注释一并清理——消费点没了）。
- WA `/baseline/retry` 路由与 `isValidAgentApiKey` 删除；`luban-cad/scripts/{regenerate-baseline,check-imodel-status}.ts` 改调 HUB requeue。
- 至少一次投递幂等前提：MS `/api/webhook/events` 保持 log+ack、进度 POST 保持幂等覆写（本轮不得改变其语义）。
- MS config 新增必填 `IMODELHUB_API_KEY: z.string().min(32)`（根 .env/generate-env 已有值）。
- 轮询保留为兜底：FE `live===false` 时 5s refetchInterval 必须回得来。
- HUB 仓提交：pre-commit lint 若遇存量 ~45k CRLF/prettier 报错则带据 `--no-verify`（触及文件单独 lint 干净），提交信息注明。
- 已知存量失败不掩盖：MS `projects/service.test.ts`（T2.2 账）、HUB disk-health（仓内存量）。
- 提交信息结尾 `Co-Authored-By: Claude Code <noreply@anthropic.com>`。
