# B 数据模型 P2 实施计划（新文档走 B）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 让新文档真正按 B 模型工作：iTwin=项目、iModel=文档、Part Studio=文档内的 Model/scope；文档中心读取 B；旧 A 文档只读兼容；多 Part Studio 页签切换不新建 BriefcaseConnection。

**Architecture:** 保留现有 `/documents/:iTwinId/:iModelId?model=<scopeId>` 路由和 `WorkspaceRef`。在 iTwin `data.luban.modelMode='B'` 标记新项目；未标记的 iTwin 视为 A 旧文档。Part Studio 注册表落在 iModel 内容层：def partition 的 `JsonProperties.luban.partStudio = {id,name,order,createdAt}`，scope id 为服务端生成的 UUID，标签仍为 `LubanFeaturePartition:<id>`。新增 RPC 注册表方法，契约升到 `1.18.0`。文档创建 = 在 B 项目下建 iModel，baseline 初始化后显式创建默认 Part Studio；任何 B 读 RPC 之前必须先解析/创建 scope，禁止让 legacy RPC 抢先建 legacy 分区。

**Tech Stack:** React 18 + Vite + Vitest + Playwright；`@itwin/core-backend` StandaloneDb/EditTxn/ECSQL；pnpm workspace；modeling-server RPC；hub NestJS/TypeORM。

**Spec:** `docs/adr/0001-itwin-imodel-data-model.md`（P2 段 + §8.2/§8.5）+ `docs/superpowers/plans/2026-10-30-b-model-p1-spike.md`（P1 已交付 API）。

| # | 决策 | 理由 / 代价 |
|---|---|---|
| D1 | **Project 标记**：新 B 项目 iTwin `data.luban.modelMode='B'`（`schemaVersion:1`）；未标记 iTwin = A 旧文档。 | 复用现有 `itwin.data`，hub 无需迁移；代价：B 项目下所有 iModel 都视为文档。 |

| D3 | **默认 Part Studio**：B 文档 baseline 初始化后由 RPC **显式创建**；编辑器在 scope 解析前不得发任何 legacy RPC。 | 防止读 RPC 懒建 legacy 分区；代价：创建文档多一步，需失败补偿/重试。 |
| D4 | **A 只读**：P2 仅 UI 只读门（未标记项目 + 无 `?model=`）；服务端不全局拒绝 A 写。 | 不误伤空 B iModel；代价：API 层仍可写 A，P4 再服务端收口。 |
| D5 | **文档中心 IA**：`/documents` 分「项目（B）」与「旧文档（A）」两区；B 项目详情页列 iModel 文档；A 详情页保留旧 iModel=Part Studio 语义并只读。 | 保留旧路由/数据；代价：页面双模式分支与测试成本。 |
| D6 | **文档 actions**：B 文档 rename/delete/favorite/share 改走 iModel API（`PATCH/DELETE /imodels/:id`、iModel favorites、`isSecured` 权限）；A 文档继续走 iTwin。 | 文档级语义正确；代价：Share 对话框双模式。 |
| D7 | **页签**：TabBar 读注册表 scope 列表；点击 = `?model=` 切 URL，不新建 BriefcaseConnection；删除/重命名走 RPC。 | Onshape 式页签；代价：删除/最后一个 scope 的守卫。 |
| D8 | **视口**：active scope 的 `physModelId` 传入 viewer，只显示该 PhysicalModel；切页签重新 fit。 | 多 Part Studio 同 iModel 必须过滤；代价：viewer API 扩展。 |
| D9 | **Feature flag**：`VITE_B_MODEL_ENABLED`（默认 false）控制 B 项目/文档创建与文档中心 B 区；测试/e2e 显式 true。 | 可回滚不还原数据；代价：两套 UI 分支需测试。 |
