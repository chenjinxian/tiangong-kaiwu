## Task 1：画布 body 选中桥

**Files**
- 新增 `src/modules/part-studio/hooks/useCanvasBodySelection.ts`（+ test）
- `src/modules/part-studio/PartStudioPage.tsx`（PartStudioSession 单点挂载）

**Requirements**
1. Hook 签名：`useCanvasBodySelection(connection: BriefcaseConnection | undefined, bodies: readonly BodyInfo[] | undefined): void`。
2. 仅当 `connection` 且 `bodies !== undefined` 时订阅 `connection.selectionSet.onChanged`；
   挂载时先同步读取一次当前 `elements`。卸载/连接变化取消订阅（用 addListener 返回值）。
3. 事件后**以当前 elements 集为权威**（不应用事件 delta）：按 element id 映射到
   `active && authored !== false` 的 body → `{ kind: 'part', id: body.bodyKey, label: body.name }`；
   顺序按 elements 迭代序；同一 body 去重。
4. 非 body element（草图/项目范围装饰/其它模型元素）忽略。若映射结果为空 → 写 `[]`。
   `bodies === undefined` 时完全不接管（legacy 回退保持现状）。
5. 写 store 前比较稳定 key（kind+id+label 序列）；相同则不再 set（避免无意义重渲染）。
6. **不**写 `tree.selectedNodeIds`（避免 canvas→tree→emphasize 双高亮/回环）；
   树→画布仍由现有 `useCanvasSelection` emphasize 承担。
7. 单点挂载：在 `PartStudioSession` 调用一次；用
   `featureSystem.bodiesLoaded ? featureSystem.bodies : undefined`，不得在 FeatureTree/
   FeatureDialog/SketchDialog 再挂。缺 viewport 不依赖（只用 connection）。
8. 测试（vitest）：
   - fake `selectionSet { elements:Set, onChanged: { addListener } }`；触发监听 → store 得到 part 选中；
   - 空集 → `[]`；非 body id 忽略；inactive/consumed body 忽略；bodies undefined 不订阅；
   - 相同集合重复触发不重复写入（可 spy store setter 或比较引用）；
   - cleanup 取消监听；连接替换后旧监听不生效。
   - `PartStudioPage.test.tsx` 的 partial mock 若因新 hook 需要 `selectionSet`，补空实现。

**Acceptance**
- web 单测全绿；tsc/lint 干净。
- 在真实栈（Task 3）通过 `page.evaluate` 调 `vp.iModel.selectionSet.replace([body2Key])` 后，
  画布右键菜单显示 body 名称；不需要真实鼠标 pick。

## Task 2：树变异接线 + 零件行守卫 + 逐 body 可见性

**Files**
- `components/PartStudioSidebar.tsx`（applyOp/canEdit 透传 + handlers）
- `PartStudioPage.tsx`（Sidebar 传 applyOp/canEdit）
- `tree/FeatureTree.tsx`（菜单路由、part 行守卫、visibility handlers、canEdit）
- `tree/TreeRow.tsx`（主行 + 尾部 eye IconButton 结构）
- `PartStudioPage.css`（行 wrapper/eye 样式）
- i18n `common/i18n/locales/{zh-CN,en}/part-studio.json`
- tests：`FeatureTree.test.tsx` + 新增 `PartStudioSidebar.test.tsx`（或 Page 集成测试）
- e2e 选择器修正：`e2e/newbody.spec.ts`、`e2e/boolean-bodies.spec.ts`
  （新增 eye 按钮后 `partList.getByRole('button').count()` 会翻倍 → 改为主行定位）

**Requirements**
1. `PartStudioSidebar` 新增 props：`applyOp?: (op: FeatureOp) => Promise<FeatureOpResult>`、
   `canEdit?: boolean`；Page 从 `featureSystem` 传入。FeatureTree 新增同名 handlers/canEdit。
2. **特征删除**：确认 HITL 后 `applyOp({kind:'deleteFeature', featureId: node.id, ...(targetBodyId ? {targetBodyId} : {})})`；
   成功 `IModelApp.notifications` Success toast；失败 Error toast（含 result.error/异常）；
   不乐观改树（refresh 由 applyOp 内部 onCommitted 触发）。
3. **特征抑制**：`applyOp({kind:'setFeatureSuppressed', featureId: node.id, suppressed})`；
   成功/失败 toast 同上。仅 feature 节点可路由。
4. **零件行守卫**：PartNode 不得进入 edit/delete/suppress/rename 特征路径。
   - 树菜单对 part 行只显示「隐藏/显示」；移除编辑/删除/抑制/重命名项（避免 bodyKey 当 featureId）。
   - 仍保留 eye toggle（下方）与右键隐藏。
   - 双击行对 part 无行为（现状）。
5. **canEdit=false**：删除/抑制菜单项保持渲染但 `disabled`（带可见 title 提示），
   handlers 同时做防御性拒绝；不得发起 applyOp；隐藏/显示仍可用（会话态）。
6. **逐 body 可见性**：
   - TreeRow 改为 wrapper（`li > div`）：主行按钮保持原 `data-testid="tree-row-${id}"`、
     accessible name/name 文本/行选中/右键/双击语义不变；尾部新增
     `IconButton size="small" styleType="borderless"` eye，testid
     `tree-row-visibility-${id}`，`aria-pressed={isNodeHidden(node)}`，
     label=`partStudio.tree.hideBody/showBody`（zh/en），stopPropagation 不触发行选中。
   - 仅 part 行渲染 eye；点击隐藏调 `hideNodes([id])`，显示调 `showNodes([id])`；
     不直接调 EmphasizeElements（由 FeatureTree 现有 consumed∪manual neverDrawn effect 重算）。
   - part 行右键菜单增加「隐藏/显示」，同 store 通道。
   - i18n 新键 zh/en 同步（REQUIRED 表）。
7. **e2e selector 修正**：把 part 行计数改为主行按钮（例如
   `partList.locator('[data-testid^="tree-row-"]')` 或 `[data-testid^="tree-row-"]:not([data-testid^="tree-row-visibility"])`），
   保留原有 accessible name 断言；不得改变行名/顺序。
8. 单测：
   - FeatureTree 删除/抑制回调仍带 targetBodyId；新增 Sidebar applyOp 精确载荷/成功失败 toast；
   - part 行菜单无 edit/delete/suppress；eye toggle 调 hide/show 且不触发行 select；
   - canEdit=false 禁写；eye 仍可用；隐藏行 `data-hidden`/`aria-pressed` 呈现；
   - 行主按钮 accessible name、双击/右键不回归。

**Acceptance**
- web 单测/tsc/lint 全绿；既有 e2e 编译（`--list`）。
- 无真实栈断言（Task 3）；无 MS/web 产物重建。
