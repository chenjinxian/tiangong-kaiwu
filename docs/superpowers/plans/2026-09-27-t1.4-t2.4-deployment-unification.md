# T1.4+T2.4 部署链统一 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]` 语法为跟踪).

**Goal:** 根 compose 单命令全栈 + nginx 单域名反代 + WS cookie 双读 + HUB baseline 家族鉴权 + verify-stack 验收命令。

**Architecture:** 根 docker-compose.yml 编排六服务（infra+HUB+WA+MS+web+nginx），env 单源于根 .env；MS 容器化为预裁决风险点（产物进镜像先行、host-network 回退）；反代后同源 cookie 鉴权（服务端双读、FE 零改动）；HUB guard 以 AGENT_API_KEY 与应用侧 IMODELHUB_API_KEY 同值注入。

**Tech Stack:** Docker Compose、nginx、Node/Express（cookie 解析手写，零新依赖）、NestJS Guard、PowerShell。

**Spec:** `docs/superpowers/specs/2026-09-27-t1.4-t2.4-deployment-unification-design.md`

## Global Constraints

- env 单源=根 `.env`（compose `env_file` + 变量映射）；HUB env 名 `AGENT_API_KEY` 与应用侧 `IMODELHUB_API_KEY` 同值（compose 里 `${IMODELHUB_API_KEY}` 注入两处）。
- HUB guard env 缺失→**启动即 fail-fast**（防裸奔默认）；脚本无 key→退出非零。
- WS 鉴权顺序：cookie `luban_cad_auth`（JSON, tokens.accessToken）→ `?token=` query 回退；校验链（/auth/me 转发+缓存）不变；FE 零改动。
- nginx：WS Upgrade 头透传、`proxy_read_timeout 3600s`；路由表按 spec §2 前缀集。
- MS 容器化失败（link: 依赖无法在镜像内解析/构建超限时）→ `profiles: [host]` host-network 形态为**已裁决回退**，记录于实施报告与 CLAUDE.md，非失败。
- 不做 TLS/多机；HUB 仓自有 compose 保留（CI 用）。
- 提交信息结尾 `Co-Authored-By: Claude Code <noreply@anthropic.com>`；HUB 仓提交沿用「触及文件 lint 干净 + 带据 --no-verify」惯例。
